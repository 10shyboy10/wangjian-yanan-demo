# Wangjian Yanan public demo

This repository contains only the public static release of the Chinese-language heritage walkthrough. GitHub Actions publishes `wangjian-yanan-demo/site-public` to GitHub Pages when changes reach `main`.

The site retains the Zaoyuan residence, Yangjialing Central Auditorium, historical introductions, guided movement, and object inspection. Reference photographs without confirmed public redistribution rights are omitted; source links remain in the in-app evidence panels. Blender and Unreal Engine source projects are not included in this public repository.
