# Wangjian Yanan public demo

This repository contains the public static release of the Chinese-language heritage walkthrough. GitHub Actions publishes `wangjian-yanan-demo/site-public` to GitHub Pages when changes reach `main`.

Website: https://10shyboy10.github.io/wangjian-yanan-demo/

The site retains the Zaoyuan residence, Yangjialing Central Auditorium, historical introductions, guided movement, object inspection and background music. Compressed reference photographs load when their information panels are opened and support enlargement. Original source links, attribution and resource notes remain available in the panels and resource manifests.

Blender and Unreal Engine source projects are not included in this public repository.
